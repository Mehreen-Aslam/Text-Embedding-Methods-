# Text Embedding Methods

This project demonstrates different methods for converting text documents into numerical vector representations using Python.

## Methods Used

- **Bag of Words (BoW)**
- **TF-IDF**
- **Word2Vec**

## Dataset

The project uses the **20 Newsgroups** text dataset with four categories:

- `sci.space`
- `rec.sport.baseball`
- `comp.graphics`
- `talk.politics.misc`

## Features

The notebook includes:

- Text preprocessing
- Bag of Words embeddings
- TF-IDF embeddings
- Word2Vec embeddings
- Comparison of embedding methods
- PCA-based document visualization
- Document vector heatmaps
- Cosine similarity between documents
- Interactive visualization using Plotly and ipywidgets

## Requirements

Install the required libraries using:

```bash
pip install -r requirements.txt
```

## Notebook

Open:

`text_embedding_methods.ipynb`

and run the cells in order.

## Purpose

The purpose of this project is to understand how different text embedding methods represent documents as numerical vectors and how these representations can be analyzed and compared.
